User chose (2026-10-29) the hybrid route for running macOS apps on Darling: keep Darling's libSystem/xnu emulation ([[darling-xnu-port]]), load the user's own Apple AppKit/SkyLight/CoreGraphics from the BaseSystem dyld shared cache, and write a replacement WindowServer shown via Wayland/X11. Goal stated by user: polished enough to attract GitHub stars; target universal x86_64 + arm64. First app milestone: BaseSystem apps (pilot: Terminal.app).

**Why:** reimplementing AppKit for macOS 26 apps clean-room would take years; Apple binaries must never be committed or redistributed.

**How to apply:**
